##   4\. New Directive Implementation (wrangler-core module)

* **Prompt 10:** "Create a new Wrangler directive class named `AggregateStats` in the `wrangler-core` module. This class should implement the `Directive` interface and be responsible for aggregating data based on byte size and time duration columns."
    * *Explanation:* This is a high-level prompt to create the directive class.
* **Prompt 11:** "Implement the `define()` method for the `AggregateStats` directive. This method should:
    * "a.  Define the directive's syntax: `aggregate-stats :<size_column> :<time_column> <target_size_column> <target_time_column> [output_size_unit] [output_time_unit] [aggregation_type]`."
    * "b.  Specify that `<size_column>` and `<time_column>` must be columns containing `BYTE_SIZE` and `TIME_DURATION` values, respectively."
    * "c.  Define the four required arguments: source size column, source time column, target column for total size, and target column for total or average time."
    * "d.  Define the optional arguments: `output_size_unit`, `output_time_unit`, and `aggregation_type` (with a default value of 'total')."
    * "e.  Include clear documentation for each argument."
    "
    * *Explanation:* This prompt provides detailed instructions for defining the directive's syntax and arguments.
* **Prompt 12:** "Implement the `execute()` method for the `AggregateStats` directive. This method should:
    * "a.  Operate as an aggregate directive, accumulating totals across rows."
    * "b.  Use a store (within the `ExecutorContext`) to hold the running totals for size and time."
    * "c.  For each row:
        * "i.  Read the `BYTE_SIZE` value from the `<size_column>` and convert it to bytes."
        * "ii. Read the `TIME_DURATION` value from the `<time_column>` and convert it to nanoseconds."
        * "iii. Add these values to the running totals in the store."
    * "d.  In the finalization step (or last `execute` call):
        * "i.  Retrieve the final totals from the store."
        * "ii. Convert the totals to the specified `output_size_unit` and `output_time_unit` if provided."
        * "iii. Create a new `Row` containing the target columns with the calculated aggregate values."
    "
    * *Explanation:* This prompt provides detailed instructions for the directive's execution logic, including aggregation, unit conversions, and output row creation.
